# Starter question bank

This pack contains **135 original, AI-assisted exercises based on 45 independent
grammar contexts**. Each context has a multiple-choice, constrained fill-in, and
error-correction/sentence-building version. The content targets the three tenses
already supported by TenseLab. No paid Gemini request is made by the loader.

| Tense | Multiple choice | Fill in | Correction / sentence building | Total |
|---|---:|---:|---:|---:|
| Present simple | 15 | 15 | 15 | 45 |
| Present continuous | 15 | 15 | 15 | 45 |
| Past simple | 15 | 15 | 15 | 45 |

Each tense/format has three exercises at each difficulty from 1 to 5. Every
exercise has a key, a Vietnamese explanation and a grammar rule. Difficulty
levels are editorial estimates, not calibrated measurements. All eight existing
grammar skill codes occur in the pack. Distractor error mappings are left null
rather than presenting an unverified diagnosis as fact.

## Import through the deployed website

After building the backend locally once (`npm run build`), use the teacher/staff
credentials in your local `.env` to import through the real authenticated API:

```sh
npm run db:seed:curriculum -- --api-url https://tenselab.nhatlonh.id.vn --dry-run
npm run db:seed:curriculum -- --api-url https://tenselab.nhatlonh.id.vn
```

An explicit `CURRICULUM_IMPORT_TOKEN` can supply a different staff access code.
Tokens are sent as bearer credentials over HTTPS and are not printed. The loader
previews the whole pack before writing, then imports in batches of at most 50
through the existing teacher-import endpoint. Each batch is atomic; if interrupted
after some batches, rerunning skips questions already saved. This mode needs no
Docker rebuild or native SQLite dependency on your local machine.

API imports have the existing `teacher_import` provenance and the authenticated
teacher as creator. That endpoint uses its existing `model=human` ingestion tag;
every question's grammar-rule note explicitly discloses **AI-assisted authorship**.
The loader does not claim these questions were generated by Gemini or reviewed by
a teacher. All records remain drafts for the normal administrator review.

## Alternative: load from the Linux server

Copy the updated repository files to the server, including
`scripts/seed-curriculum.mjs`. From the project folder on the **Linux server**:

```sh
cd /srv/AI-English
docker compose exec -T api node --input-type=module - --dry-run < scripts/seed-curriculum.mjs
docker compose exec -T api node --input-type=module < scripts/seed-curriculum.mjs
```

This streams the loader into the running API container. It uses the existing
compiled application and environment, writes to the existing SQLite data volume,
and does not require a Docker image rebuild or a service restart. It works with
the deployment image created before this pack was added.

The dry run validates all questions and reports coverage without opening a
database. The second command normally reports `added: 135` and `skipped: 0`.
Running it again reports `added: 0` and `skipped: 135`. Existing matching questions,
including any edited content or rejection/approval decisions, are preserved.
New questions are imported in one transaction after validation.

## Review, publish, then practise

1. Sign in as an administrator using a configured staff access code.
2. Open **Ngân hàng câu hỏi** and choose the **draft/chờ duyệt** filter. The
   provenance is `ai_assisted_curriculum` (the updated frontend labels it
   **Học liệu khởi đầu (AI hỗ trợ)**).
   When imported through the API, choose source **Nhập từ tệp** (`teacher_import`)
   instead and identify the AI-assisted starter note in the grammar rule.
3. Inspect the question, answer key, distractors and explanation. Use the normal
   approval action, tick the existing grammar/answer review confirmation, and
   enter a meaningful review note. Reject questions that need revision.
4. Publish questions in all three formats and tenses you want to offer. A student
   can then start practice, or a teacher can select approved questions for an
   assigned exercise.

Both import paths write **drafts**, matching the application's existing
publication rule. The direct database loader records
`createdBy=system:tenselab-starter-v1` and `model=codex-authored`; the API path uses
the existing teacher-import metadata described above. Neither invents a human
reviewer or approval time. Neither replaces a teacher's review of the content.

This pack contains learning content only. Student accounts, attendance, attempts,
scores and research results are populated by actual classroom use. After
deployment, staff can create students and obtain access codes through the normal
student-management flow; the local QA-account seeder is not used.

## Local development

With dependencies and the database prepared:

```sh
npm run build
npm run db:seed:curriculum -- --dry-run
npm run db:seed:curriculum
```

Use the same Node major version that your native `better-sqlite3` dependency was
installed for. The Docker deployment uses Node 24.

## Content references and scope

The sentences and Vietnamese explanations in this repository are original; they
are not copied exercise sets or a validated educational research dataset.
Grammar reference pages for teacher review:

- [British Council: Present simple](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference/present-simple)
- [British Council: Present continuous](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference/present-continuous)
- [British Council: Past continuous and past simple](https://learnenglish.britishcouncil.org/free-resources/grammar/a1-a2/past-continuous-past-simple)

No claim is made that the pack follows a particular Vietnamese textbook, has been
teacher-certified, or establishes student learning outcomes. Research reports
retain its separate provenance.
