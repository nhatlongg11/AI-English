# Nguồn component

- shadcn/ui: component source tải từ [official new-york-v4 registry](https://ui.shadcn.com/r/styles/new-york-v4/button.json), tương tự các tên card/chart/dialog/sidebar/…; [source và MIT license](https://github.com/shadcn-ui/ui/blob/main/LICENSE.md). Import registry aliases được đổi thành aliases local `@/components/ui`, `@/hooks`, `@/lib/utils`. Không dùng package `cn` bên ngoài.
- shadcn Charts: [tài liệu](https://ui.shadcn.com/docs/components/chart), ChartContainer/Tooltip từ official registry, Recharts 3.10.1 tương thích yêu cầu registry 3.8+.
- React Bits CountUp: [component](https://reactbits.dev/text-animations/count-up), registry `https://reactbits.dev/r/CountUp-TS-TW.json`; license MIT + Commons Clause của David Haz nằm cùng component tại `frontend/src/components/rewards/REACT_BITS_LICENSE.md`. Sử dụng trong sản phẩm TenseLab, không phân phối như bộ component thương mại.
- dnd-kit: [quickstart hiện tại](https://dndkit.com/react/quickstart/), package @dnd-kit/react 0.5.1 và @dnd-kit/helpers 0.5.1; không dùng legacy @dnd-kit/core API.
- Motion, Recharts, Radix UI, Lucide và các dependency npm giữ license tại package tương ứng trong node_modules/lockfile.
- Shepherd.js **15.3.0**: [official usage](https://docs.shepherdjs.dev/guides/usage/), [styling](https://docs.shepherdjs.dev/guides/styling/), [license](https://github.com/shipshapecode/shepherd/blob/main/LICENSE.md). Package declares **AGPL-3.0** and upstream offers a commercial license; it is not MIT. License retained in `node_modules/shepherd.js/LICENSE.md`. Integration is for this local educational application; a commercial distribution needs review against the upstream terms. TenseLab's custom classes and theme stylesheet live in `frontend/src/features/guidance/tour.css`; static tour text is inserted as DOM text, without user HTML or analytics.
